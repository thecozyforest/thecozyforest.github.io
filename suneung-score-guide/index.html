원본 제작 박상근 선생님 · 변형 제작 기경민 선생님
박상근 선생님의 허가를 받아 변형했습니다.

학교별로 빈 양식을 복사해 학생용 웹앱을 배포합니다. 학생은 공통 주소 하나에서 반·번호·이름·점수를 제출하고, 담임은 공유받은 반별 시트에서 점수와 제출 현황을 확인합니다.

초기 공개판에서는 학생 이름을 받지 않았습니다. 대교협 가채점 엑셀 양식에 반·번호와 이름이 들어가므로, 제출용 파일을 다시 입력하는 일을 줄이기 위해 현재 공개판에는 이름 입력란을 추가했습니다. 이름과 점수는 학교의 비공개 수합 시트에 저장됩니다.

준비물 도름스용 빈 템플릿 열기

1 내 드라이브에 사본 만들기

파일 → 사본 만들기를 눌러 학교에서 운영할 Google 계정의 내 드라이브에 저장합니다. 사본의 공유를 열어 일반 액세스가 제한됨인지 확인합니다.

2 사본에서 최초 설정하기

가채점 관리 → 최초 설정을 실행합니다. 승인 창에서 사본을 만든 계정을 선택합니다. 미확인 앱 안내가 뜨면 개발자 계정과 요청 권한을 확인합니다. 승인 후 필요하면 이 메뉴를 한 번 더 실행합니다.

설정 탭에서 학년·반 수·반별 최대 번호를 확인합니다. 반마다 인원이 다르면 가장 큰 번호가 모두 선택될 수 있도록 번호 상한을 정합니다. 수합 기간에는 입력 받기를 체크합니다.

3 학생용 웹 앱 배포하기

확장 프로그램 → Apps Script → 배포 → 새 배포를 엽니다. 배포 유형에서 웹 앱을 선택하고 다음 값으로 배포합니다.

배포 항목선택
다음 사용자 인증 정보로 실행나
액세스 권한이 있는 사용자모든 사용자

최초 권한 승인 창이 뜨면 사본 소유자가 승인합니다. 배포 화면의 웹 앱 URL을 복사해 학생들에게 같은 주소를 보냅니다.

4 배포 확인하기

시크릿 창에서 웹 앱 주소를 열어 가짜 점수 한 건을 제출합니다. 학교 사본의 가채점과 제출기록에 들어왔는지 확인한 뒤 시험 행만 지웁니다.

학생에게 보낼 링크는 배포 화면에서 복사한 웹 앱 URL입니다. 도름스 게시글에는 위의 빈 템플릿 링크를 올립니다.

점수 수합과 담임 공유

수합 담당자는 학교 사본에서 전체 점수와 제출기록을 확인합니다. 담임에게는 담당 반만 담긴 별도 파일을 공유합니다.

담임용 파일 만들고 갱신하기

가채점 관리 → 담임용 시트 만들기·새로고침에서 반 번호를 입력합니다. 여러 반은 1,3,5처럼 입력하면 한 파일에 모입니다. 열린 파일에서 공유 → 일반 액세스 제한됨을 확인하고 해당 반 담당자를 뷰어로 추가합니다. 같은 반 조합으로 다시 실행하면 기존 파일이 갱신됩니다.

담임은 번호순 제출 목록을 반 명단과 대조합니다. 중간에 빠진 번호는 미제출인지 결번인지 확인합니다.

역할별로 열람 범위 정하기

역할공유할 파일권한
담임담당 반 파일뷰어

대교협 제출용 엑셀 만들기

앱은 대교협 양식에 붙여넣을 데이터를 만듭니다. 제출용 .xlsx는 대교협 원본 엑셀에서 저장합니다.

  1. 학교 수합 시트에서 가채점 관리 → 대교협 양식 복사용 시트 만들기를 실행합니다.
  2. 안내 창을 닫고 자동으로 선택된 A4:S 데이터 행을 복사합니다. 학생이 제출한 이름은 대교협 양식의 E열에 들어갑니다.
  3. 학교에서 받은 대교협 원본 엑셀의 저장 탭 A4에 값으로 붙여넣기 합니다. 이름과 반·번호를 확인한 뒤 원본 양식의 사본을 .xlsx로 저장합니다.
  4. 학교 담당자가 고교용 대입상담프로그램에서 해당 파일을 등록하고, 등록 결과를 확인한 뒤 전송합니다.

최신 템플릿으로 만든 학교 사본부터 학생 입력에 이름 칸이 표시됩니다. 이전에 만든 학교 사본은 기존 방식으로 동작합니다.

학생 제출과 마감 처리

학생은 로그인 없이 반·번호를 선택하고 이름, 과목별 원점수 또는 미응시를 입력합니다. 제출 직전 학년·반·번호·이름을 확인합니다. 처음 제출한 탭에서는 내용 고치기로 바로 수정할 수 있습니다.

새 탭에서 정정 요청하기

  1. 학생이 공통 링크를 다시 열어 수정한 점수를 입력하고 제출합니다. 이미 제출된 번호라면 반·번호를 확인하고 본인 점수인 경우 정정 요청 보내기를 누릅니다.
  2. 담당자는 학교 수합 시트에서 가채점 관리 → 정정 요청 보기를 열어 요청을 확인합니다. 학생과 점수를 확인한 뒤, 해당 행을 선택하고 선택한 정정 요청 승인을 누릅니다. 잘못된 요청은 선택한 정정 요청 반려로 처리합니다.
  3. 승인하면 가채점 탭의 기존 행이 갱신되고 화면이 그 행으로 이동합니다. 처음부터 반·번호를 잘못 골랐다면 담당자가 실제 학생의 번호와 기존 제출 행을 먼저 대조합니다.

도름스의 공개 미리보기에서는 입력값을 저장하지 않습니다. 학생에게는 학교의 비공개 사본에서 별도로 배포한 주소를 보내세요. 이미 배포한 학교별 사본에는 새 기능이 자동으로 반영되지 않습니다.

마감은 설정 탭의 입력 받기 체크를 해제합니다. 제출기록은 학번·시각·신규 또는 수정 여부를 남깁니다. 정정요청 탭도 학교 수합 시트 안에서 관리합니다. 상담에 필요한 기간이 지나면 학교의 보유·파기 절차에 따라 수합 시트와 반별 파일을 정리합니다.

막혔을 때 확인할 것

상황확인
가채점 관리가 안 보임복사한 시트를 편집 가능한 계정으로 새로고침합니다.
학생 화면이 로그인이나 권한을 요구함배포자의 최초 승인, 웹 앱 URL, 액세스의 모든 사용자 설정을 확인합니다. 선택 항목이 없으면 학교 Google 관리자에게 문의합니다.
담임에게 점수가 늦게 보임수합 담당자가 같은 반의 담임용 시트 만들기·새로고침을 다시 실행합니다.
