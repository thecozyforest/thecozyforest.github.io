원본 제작 박상근 선생님 · 변형 제작 기경민 선생님
박상근 선생님의 허가를 받아 변형했습니다.

학교별로 빈 양식을 복사해 학생용 웹앱을 배포합니다. 학생은 공통 주소 하나에서 반·번호와 점수를 제출하고, 담임은 공유받은 반별 시트에서 확인합니다.

준비물 도름스용 빈 템플릿 열기

1 내 드라이브에 사본 만들기

파일 → 사본 만들기를 눌러 학교에서 운영할 Google 계정의 내 드라이브에 저장합니다. 사본의 공유를 열어 일반 액세스가 제한됨인지 확인합니다.

2 사본에서 최초 설정하기

가채점 관리 → 최초 설정을 실행합니다. 승인 창에서 사본을 만든 계정을 선택합니다. 미확인 앱 안내가 뜨면 개발자 계정과 요청 권한을 확인합니다. 승인 후 필요하면 이 메뉴를 한 번 더 실행합니다.

설정 탭에서 학년·반 수·반별 최대 번호를 확인합니다. 반마다 인원이 다르면 가장 큰 번호가 모두 선택될 수 있도록 번호 상한을 정합니다. 수합 기간에는 입력 받기를 체크합니다.

3 학생용 웹 앱 배포하기

확장 프로그램 → Apps Script → 배포 → 새 배포를 엽니다. 배포 유형에서 웹 앱을 선택하고 다음 값으로 배포합니다.

배포 항목선택
다음 사용자 인증 정보로 실행나
액세스 권한이 있는 사용자모든 사용자

최초 권한 승인 창이 뜨면 사본 소유자가 승인합니다. 배포 화면의 웹 앱 URL을 복사해 학생들에게 같은 주소를 보냅니다.

4 배포 확인하기

시크릿 창에서 웹 앱 주소를 열어 가짜 점수 한 건을 제출합니다. 학교 사본의 가채점과 제출기록에 들어왔는지 확인한 뒤 시험 행만 지웁니다.

학생에게 보낼 링크는 배포 화면에서 복사한 웹 앱 URL입니다. 도름스 게시글에는 위의 빈 템플릿 링크를 올립니다.

점수 수합과 담임 공유

수합 담당자는 학교 사본에서 전체 점수와 제출기록을 확인합니다. 담임에게는 담당 반만 담긴 별도 파일을 공유합니다.

담임용 파일 만들고 갱신하기

가채점 관리 → 담임용 시트 만들기·새로고침에서 반 번호를 고릅니다. 열린 반별 파일에서 공유 → 일반 액세스 제한됨을 확인하고 해당 담임의 Google 계정을 뷰어로 추가합니다. 같은 반으로 다시 실행하면 기존 파일의 자료가 갱신됩니다.

담임은 번호순 제출 목록을 반 명단과 대조합니다. 중간에 빠진 번호는 미제출인지 결번인지 확인합니다.

역할별로 열람 범위 정하기

역할공유할 파일권한
담임담당 반 파일뷰어

학생 제출과 마감 처리

학생은 로그인 없이 반·번호를 선택하고 과목별 원점수 또는 미응시를 입력합니다. 제출 직전 반·번호를 확인합니다. 같은 탭에서는 내용 고치기로 수정할 수 있으며, 탭을 닫았거나 첫 제출의 반·번호가 틀렸다면 수합 담당자에게 정정을 요청합니다.

마감은 설정 탭의 입력 받기 체크를 해제합니다. 제출기록은 학번·시각·신규 또는 수정 여부를 남깁니다. 상담에 필요한 기간이 지나면 학교의 보유·파기 절차에 따라 원본과 반별 파일을 정리합니다.

막혔을 때 확인할 것

상황확인
가채점 관리가 안 보임복사한 시트를 편집 가능한 계정으로 새로고침합니다.
학생 화면이 로그인이나 권한을 요구함배포자의 최초 승인, 웹 앱 URL, 액세스의 모든 사용자 설정을 확인합니다. 선택 항목이 없으면 학교 Google 관리자에게 문의합니다.
담임에게 점수가 늦게 보임수합 담당자가 같은 반의 담임용 시트 만들기·새로고침을 다시 실행합니다.
